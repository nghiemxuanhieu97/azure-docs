# Question 1
Which four characteristics best describe Consumption-based pricing model.
- [x] No wasted resources
- [ ] Upfront payment
- [x] Pay for what you use
- [ ] Volume licensing
- [x] Stop paying when you don't need resources
- [x] No upfront payment
>**Note:** Consumption based model means that customers only **pay when they use resources**, as such 
they have **no upfront cost** associated. Because of that you can create resources at any time and delete them at any time, 
so you **don’t waste any resources**. **Once resources are deleted, customers stop paying.**

# Question 2
Each service in the cloud has multiple small consumption-based metrics which combined make up for the service cost. 
This allows the cloud provider to charge their customers appropriately for their usage. True or false?
- [x] True
- [ ] False
>**Note:** This sentence is **true**. Charging for services is a complicated process to get right. In order to charge 
customers appropriately for their usage, cost of each service is divided in smaller metrics measuring different aspects 
of customer usage. Example would be Virtual Machine Size, Associated Disk (HDD vs SSD), Networking Bandwidth, etc.
